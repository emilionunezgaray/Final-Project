# Movie Theater Billboard

## **Project Overview**
My final project will be a **Movie Theater Billboard** website displaying:
- A list of films with details (title, genre, showtimes, and ticket prices).
- Filtering by genre, price segment, and time.
- A booking form to select seats and determine the total cost.

### **Why This Project?**
I have picked this project because it combines "front-end and back-end" skills:
- **C# API** to return movie information.
- **JavaScript** to do dynamic page loading and form submission validation.
- **CSS styling** to make the page feel engaging with a simple view.
All this is a way of also demonstrating my own enjoyment of film and a great website that's not only interactive and fun, but easy on the eyes, as well.
